# 方法论

每一集、每一个新出现的事物，都必须按"正向流程"讲完，不允许凭空出现、不允许跳步。

## 正向流程六步

1. **前提**：当时的世界是什么样，已经有什么
2. **形成**：新东西从哪来，一步步怎么形成
3. **变化**：为什么会变，原因 → 结果，用画面或指示条让变化看得见
4. **概念**：新词第一次出现就用一句大白话解释
5. **影响**：它改变了什么，和你有什么关系
6. **引出**：这个变化成为下一集的前提

## 写稿自查

- 这个东西是从哪来的？前面讲过吗？
- 每个"所以"前面，原因讲了吗？中间有没有跳过一步？
- 有没有观众不认识的词？第一次出现时解释了吗？
- 画面尺度变了吗（太空 / 地表 / 显微镜 / 分子）？提示了吗？
- 和上一集结尾、下一集开头接得上吗？
- 有争议的结论，是否写成"可能""科学家认为"？

## 固定的引导装置

| 装置 | 作用 | 例子 |
| --- | --- | --- |
| 概念卡 | 新词第一次出现时弹出 | 板块：地壳碎成的大块，漂在炽热的地幔上 |
| 尺度提示 | 进入微观或示意画面时提示 | 显微镜下 / 分子视角（极度放大）/ 示意图 · 已放大 |
| 指示条 | 讲连锁变化时让因果看得见 | 二氧化碳、温度；需要的能量、能提供的能量 |
| 上集回顾 | 用上一集结尾画面开场 | 上一集，地球冻成了雪球 |
| 顶部时间轴 | 本季 6 个节点，当前集点亮 | 发电厂 → 雪球地球 → 分工 → … → 人类 |
| 和你有什么关系 | 每集结尾一句，落到观众身上 | 你椎间盘里的髓核，是当年脊索留下的痕迹 |
| 首尾衔接 | 本集结尾画面 = 下集回顾画面 | |

## 制作流程

1. **写稿**：按六步写旁白、字幕、概念卡、和你的关系
2. **因果审核**：制片人读稿，标出"没理解""跳步"的地方，补齐后再制作
3. **画面**：先出关键帧确认，再整集渲染
4. **配音**：生成旁白（后期统一替换为 MiniMax）
5. **混音**：旁白 + 音乐 + 音效，统一响度到 −14 LUFS
6. **成片检查**：按下方清单
7. **导出与发布**

## 成片检查清单

- [ ] 每个新事物都讲了"从哪来"
- [ ] 每个"所以"前都有原因，没有跳步
- [ ] 每个新词第一次出现都有概念卡
- [ ] 尺度切换有提示
- [ ] 开头接上一集结尾，结尾停在下一集开场画面
- [ ] 旁白、字幕、画面对得上，没有截断或重叠
- [ ] 字幕在安全区内，不被平台按钮遮挡
- [ ] 事实、年代与主流科学一致
- [ ] 响度达标，手机外放能听清
